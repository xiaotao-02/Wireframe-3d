# 共享场景约定 anatomy-3d/1

该约定用于附带示例，便于比较两引擎。它不是上游格式，也不要求所有未来作品只能使用三角网格。

新 Three.js 主题可改用 [buildScene 构建器](component-library.md)，不必转成泵清单；该 JS 入口不由 `build_blender.py` 读取。跨引擎交付仍需明确坐标、部件 ID 和状态对应。

## 坐标与部件

- 右手系，Z 向上，长度单位米，角度弧度。Three.js camera.up 设为 `(0,0,1)`，不对整个世界重复做轴转换。
- `groups[]`：`id`、`label`、`rest[3]`、`explode[3]`，可选 `spin: x/y/z`、`cover: true`。示例为平级组；复杂装配可扩展 parent 字段，但两端都须实现并检查无环。
- `parts[]`：`id`、`label`、`group`、`pos[3]`、`rotation[3]`、`color`（sRGB hex）、`smooth`、`note`、`mesh`。
- `mesh.vertices` 为局部坐标；`mesh.faces` 为 CCW 三角形索引。旋转再平移到所属组。x/y/z 旋转组合为 `Rz @ Ry @ Rx`：Three.js Euler order 用 `ZYX`，Blender 用默认 `XYZ`。禁止盲目把两个引擎的同名 Euler order 当成相同组合。
- 组位置 `rest + e * explode`，`e ∈ [0,1]`；零件位置不做累计修改。组旋转后才变换其局部子物体。
- `flow[]` 为世界坐标示意折线路标。网页做平滑曲线、Blender 做折线，因此两端流线路径并非逐点相同；需要严格一致时预采样一份曲线再复用。

## 建模取舍

示例 54 个实体、5 组：真实壁厚的环形腔体/入口/出口，曲面叶片、轴、联轴器、带散热筋的电机壳等。环形泵腔简化真实蜗壳，省略密封、轴承内部和电机电磁结构；不能做流体、热或制造计算。

`make_demo.py` 中的 `lathe()` 为独立 Python 网格回转实现，不是复制上游 SVG `lathe.mjs`；`blade()` 为原创曲面叶片网格。`box()` 只用于底座、支座等确实适合盒体的部分。

## 检查能证明什么

`validate_scene.py` 焊接同坐标后检查每条边两次引用、三角形非退化、有向体积为正。这可以发现开边/部分绕序错误，**不保证无自交、所有面朝外、装配不碰撞或水密可制造**。保留硬边的重复顶点是合法着色设计。

还需按主题补充接口直径、中心距、最小壁厚、运动范围、间隙与相机验收。对未建模的部分明确写“省略/简化”，不要用检查通过隐藏缺失结构。
