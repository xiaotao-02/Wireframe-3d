# 连续外壳的逐轮返修

用于车辆或类似流线外壳的参考建模，以及用户反馈“过于简化”后的返修。不是车型生成器；图纸控制点、涂装和灯腔尺寸仍由具体案例提供。

## 先换表示，再加细节

对照侧面轮廓、正面开口和前后四分之三视图。平直侧板、单一横截面放样若不能独立控制翼子板鼓包、肩部、门板收腰、下沿与保险杠转角，增加采样数仍不会产生这些形体。将高影响部位拆成共用边界的曲面块，或改用可编辑细分网格；先验证一处翼子板与保险杠连接，再扩展全车。

- 分别控制纵向高度/宽度轨迹与横向截面；坡度变号处可用保形插值避免过冲。
- 拼接检查分为位置吻合和切向/高光连续。Coons 补片只解决边界插值，不能自动证明后者。
- 曲面参数在裁切边界之外仍应保留正确的一阶导数。将截面值在边界外直接夹成常数，会让中心差分算出一半坡度；相邻三角面便可能出现密集高光锯齿。可在定义域外短距离按端点切线延拓，几何仍按原轮廓裁切；随后重查实际法向与高光。局部 Hermite 修正可保持端点位置并调整跨缝切向，但过强的切向量会制造鼓包，需审图控制幅度。
- 真开孔配套孔唇、内壁、背面和可见内部。轮拱也需要轮罩内衬，透过轮辐看到背景不能靠黑色轮胎贴图修复。
- 灯罩贴附车身，投射器光轴可独立朝前；把整个灯组都按外壳法线旋转，可能把正面圆灯压成扁椭圆。
- 凹腔在急弯表面沿法线偏移可能折叠；可显式指定内缩轴，孔唇、内壁与底面必须使用同一规则。核对下唇、侧裙、扩散器的面朝向，不用全局双面材质遮掩错误。

## 从渲染缺陷找到几何原因

灰模和材质图使用固定相机，另加灯组/保险杠近景。先判断异常属于缺面、法向、阴影还是反射：可用射线命中实际网格确认亮区是否真是漏孔，避免把白色高光误改为封口。

有孔外壳经 Earcut 裁切会出现细长扇形三角形。均匀递归细分保留其长宽比；映射到急变曲率时，三角面的几何法向可能与分析法向偏离，产生条状阴影/尖刺。检查实际三角面与顶点法向、边长跨度和面积，再采用规则参数网格或有界单元裁切。别只提高递归层数。

裁孔与边界吸附先限定完整的局部作用域，再判断到边界的距离。仅选择“到某个平面的最小正距离”会误改远处的车顶或侧壁。用域外采样点确认局部操作保持其位置，再检查实际输出面：不能把多个顶点压成线/点后仍保留退化三角形。孔唇、内壁与外壳共用裁切边界；大范围折叠时回到未裁切基线重新构造，不用 `computeVertexNormals()` 或双面材质掩盖拓扑错误。

自写多边形映射时保持三角化顶点表与实际位置表完全一致。若三角化函数会移除闭环末尾的重复点，先统一清理外环与孔环，再建立索引，避免孔索引错位后被实体面封住。玻璃等贴附曲面不能只映射轮廓顶点并跨接大三角形；应在曲面域内细分，沿宿主边界采样，再核对窗框与曲面间距。已有 `trimmedGridGeometry` 能完成的映射不必另写未经检查的版本。

轮组、灯筒等旋转构件先记录原语自带轴与目标世界轴，再决定旋转。用实际网格包围尺寸和两个方向的画面核对轴向；同组轮胎、轮辋、制动盘应共轴。标注尺寸与生成参数一致不能替代这个检查。

边界曲率很大时，共享解析曲线仍不足以保证两侧离散折线吻合；检查实际采样点的偏差。按误差增加边界采样，清掉数值上近共线的冗余点并记录容差，不要关闭退化三角形检查来强行通过。

`assets/lib/surface-network.js` 提供：

| API | 用途与限制 |
|---|---|
| `monotoneProfile([[station,value],...])` | 分段保形三次插值；站位递增，区间外夹紧，平台保持常值；不推断车身曲率 |
| `gridSurfaceGeometry(surface,{uSegments,vSegments,reverse})` | 无孔规则网格；按曲面导数生成法向；分段 1–512 |
| `trimmedGridGeometry(surface,{outline,holes,uSegments,vSegments,reverse})` | 先验证 UV 轮廓，再将裁切三角形分割进有界网格单元；保留真实孔洞。UV 顶点按 1e-8 合并，跳过小于 1e-10 的 UV 双倍面积，非 CAD 密封保证 |
| `roundedContour(points,{fraction,segments})` | 在输入坐标中圆滑拐角；不是自动描图，fraction 不是毫米半径 |
| `openingBevelGeometry(surface,outline,{innerScale,depth,segments,direction})` | 孔唇缩放与内缩，返回 `{geometry,inner}`；direction 为空沿负法向，提供向量则沿该轴。缩放不是等壁厚 |

`surfaceFrame` 先归一化切向再检查夹角退化，支持毫米级有效曲面。零长度或共线切向仍须拒绝；尺度修复不等于对任意微小单位无限精度支持。

## 涂装和证据

涂装按车身世界坐标规划主色块、曲线、断片和字牌，再映射到各块 UV。分别检查机盖—翼子板、肩部—侧围、尾部的边界；左右图形可对称，文字不能镜像。不要用整张侧面照片遮盖几何错误。缺少顶部参考时注明推测，字体和商标重绘也不宣称原始贴图。

含文字的贴图先用不对称小样（向上箭头、左右标记和数字）验证实际曲面的 UV、`flipY` 与镜像变换。区分上下翻转、左右镜像和旋转 180°，确定映射后再铺完整涂装；仅查看离屏画布不能证明贴到两侧网格后的方向正确。

每轮保存“看见的问题 → 修改部位/方法 → 同机位结果”，把截图绑定当前构建哈希、相机、视口和该轮源代码。补近景不能替代固定总览。改灯光可以帮助看曲面，但改善光照不能算几何还原度提高。最终回读源代码、独立重建和交互，历史通过报告不自动适用新版本。

```powershell
node "$skillDir/scripts/verify_surface_network.mjs" --three "$workDir/vendor/three" --report "$workDir/evidence/surface-network.json"
```

这是合成几何回归；同一个汽车案例反复调优属于开发验证，不是新题材盲测，也不证明摄影级相似度。
