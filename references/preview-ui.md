# 三维预览界面

默认模板使用 `assets/web/preview-ui.css` 与 `preview-ui.js`，与模型构建、几何和过程状态分离。当前已用于离心泵起点及 Raptor/涂装车间案例；主题文案和控件绑定仍需按对象修改。

## 使用与调整

- 紧凑标题栏放模型名称、案例切换与专注模式；主要面积留给画布。控件多时用侧面板标签分组，示例为结构/部件/说明或楼层/工位/说明，简单对象可以减少分组。
- 常用播放/暂停、点火、时间轴常驻画布底部；复位与视角在画布角落。来源与技术说明放说明页，避免占用主要操作区。
- `mountPreviewUI({tabs, views, transport, ...})` 在模型和控件事件绑定后调用。`tabs` 每项为 `{id,label,element}`，`views` 是原按钮节点，`transport` 是已装入原播放控件的 DOM 容器。函数移动节点保留 ID、监听器和状态，不复制一套模型控制。
- 需要模型点选联动说明时提供 `pickControl`（原 select 节点）与 `pickTab`（目标标签 ID）；它依据画布点选后实际选择值变化切换。没有新选中对象时不强行切换。
- `transportContainer()`、`transportRule()` 和 `timelineBlock(label,input)` 提供默认底部条构造。用户指定其他布局时可以替换这些默认样式，不将固定像素或分组作为任意项目的硬约束。
- `prepare_web.py` 已复制两份共享 UI 文件；只复制旧版 index/app 会缺资源。新增主题的 `#panel`、`#stage`、`header`、`main` 应匹配模板约定。

## 可用性与验收

1. 面板切换和专注模式只改变观察界面，不重建场景或重置相位。可用 F 切换专注，Esc 返回；输入框与选择器内不拦截 F。此功能收起面板，不调用浏览器全屏。
2. 标签使用 tablist/tab/tabpanel、方向键与 Home/End。隐藏页不能残留可聚焦控件；专注模式退出后控件状态保持。暂停与状态读数来自模型原状态。
3. 原生 range 保留键盘操作，只改变轨道与滑块样式；进度填充与实际 value 同步，包括由动画更新的时间轴。
4. 布局用视口高度约束，长内容在面板内部滚动。窄屏改为上方模型、下方标签面板；实际检查画布、播放条、侧栏宽度和页面滚动范围，避免靠裁剪溢出掩盖不可达控件。
5. 悬浮 UI 必须留出模型安全空间：取景同时考虑模型横向范围与底部操作条，切换专注/窄屏触发 renderer 和 camera 的 resize。截图核对底座、管口和关键结构未被常驻控件挡住。正常缩放重开默认入口，不能先进入专注模式才让主体完整；若目标是核心局部展示，明确局部并保留通往总览的操作。
6. 改完实际操作点选、标签、拆装、播放/暂停、复位及窄屏；核对 console 和画面。仅修改 UI 时不重复宣称模型几何或完整工艺得到新的验证。

每屏先确定主信息；主体过小优先改取景与面板占比，长解释放说明页。按用户的目标显示尺寸检查文字，不用高分辨率截图放大阅读代替实际验收。标签连接真实部件，遮挡或密集时筛选、收起或随选择显示；引线不交叉覆盖关键结构。定长演示还按实际停留时间检查能否读完，避免一帧塞满信息。
