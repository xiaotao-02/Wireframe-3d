# Anatomy 浅色插画渲染

本页用于用户要求插画表达，或没有指定参考外观的结构科普。此类主题可用 `renderStyle:'anatomy-light'`；原 V4 试件显式保留 `renderStyle:'studio'`。写实参考建模先按 [参考建模与首次交付](reference-reconstruction.md) 选择呈现，显式设置合适的 `renderStyle`，不沿用模板的插画缺省值。网页可在同一模型、同一镜头切换“细线插画 / 柔光实体”。实现位于 `assets/lib/illustration.js`，这不是给 PBR 材质改色的同义词。

## 已执行的绘制方法

- 纸面 `#fbfbfa`，以原作四档浅灰为明暗范围；片元法线产生连续过渡，曲面不分割成生硬色带。
- 背面扩张壳产生屏幕尺度轮廓，EdgesGeometry 仅输出较大折角/边界；深度测试保留遮挡。没有绘制全部三角形或全部背边。
- `illustrationPalette()`：body/frame/base/metal/dark/accent/blue/red/glass 共享语义材质；使用 `materialRole(role,color)` 给自定义材质标记角色。透明材质保持原实现；实体网格缺省为 structure。
- 约 .65 CSS 像素轮廓＋低对比内部折线；Canvas 接触晕影帮助落地，不是物理投影。色调映射在插画模式关闭，避免受灯光/曝光重复改色。
- 正交主视角可从 `[1,-1,.8165]` 开始（约 45° 方位、30°俯角），按参考调方向与取景。共享 UI 安全区不能代替模型和参考同机位。

装饰节点标记 auditIgnore；不把轮廓壳计入装配实体。独立近景隐藏接触晕影。实例网格共享轮廓壳，未逐实例创建内部折线；可写专用接缝几何。大量细分面、透明排序、薄片重叠仍需实际截图。

动态实例的 `count`、`instanceMatrix` 和几何要与轮廓同步；数量减为零时不能留下旧轮廓。非均匀实例缩放的轮廓法线使用逆缩放修正，不能直接乘矩阵当成法向。材质角色控制强调用途，原材质色、实例色和顶点色仍需在最终画面确认；白模是单独观察模式，不作为恢复源配色的证据。细杆可用 `userData.lineWeight` 降低线权重，不用统一重线吞没密集结构。

## 调整范围与验收

自定义工艺色使用 `materialRole('process', '#df853a')` 等语义角色。`structure/subject/base/metal` 使用中性明暗；其他角色按原材质色生成强调色，保留多材质槽、实例色和顶点色。不要先把全部材料改成白色，再期待渲染器恢复来源颜色。白模切换暂时去色，退出应恢复这些颜色。

每次姿态改变后调用 `ink.update()`：同步实例矩阵/实际数量、替换后的几何，并在 `position.needsUpdate=true` 后刷新折线。`dispose()` 恢复原材质与实例色，释放自己的装饰资源。`userData.lineWeight` 范围为 0–2；细栏杆可用 .25–.5，0 不添加轮廓，`edges=false` 只关闭内部折线。高频变形的折线重建有成本，应按实际需要关闭并检查画面，不宣称自动提高 FPS。

机械主体用中性灰、少量当前功能强调色。工厂可配置蓝/红/橙等工艺语义，不能随机给每个构件一种颜色。来源 tokens 来自两上游 MIT 浅色样式；新 shader、轮廓及 Three.js 适配为本技能原创，保留 licenses/ 通知。

固定相机、画幅、状态，查看总览及管口、法兰、导套等关键近景。比较纸面、面明暗、线的主次、接缝连续性、色彩含义、阴影和信息密度。新题材只能比较共同视觉特征，不伪造与另一对象的像素相似度；原对象复刻另做几何参考对照。

当原作细节密度明显高于新模型，应记录差异并补有依据的构造。不要用装饰噪声或任意最低零件数填满画面；也不要用统一材质掩盖轮廓和连接问题。

剖切黑面、薄叶片背面与动态几何残影按 [展开与动作返修](explosion-and-motion-repairs.md) 处理；当前转换保留材质 side，薄片/双面曲面跳过外扩壳，`dynamicGeometry` 可跳过折线重建。展开时关闭装配态接触晕影。
